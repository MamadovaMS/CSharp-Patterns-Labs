# ОТП (Основы технологии программирования)

## 🛠 Технологии и инструменты
* **Язык:** C#
* **Платформы:** .NET Framework 4.7.2, .NET 8.0, .NET 9.0
* **UI:** Windows Forms
* **Паттерны:** Команда (Command), Стратегия (Strategy), ООП (Наследование, Полиморфизм)

## 📂 Структура проектов

### 1. `Lab1_OOP` — Основы ООП
Демонстрация базовых принципов объектно-ориентированного программирования.
* Реализована иерархия геометрических фигур: `Point`, `ColoredPoint`, `Line`, `PolyLine`.
* Использованы наследование, виртуальные методы и коллекции.

### 2. `Lab2_CommandTextEditor` — Паттерн «Команда» (Command)
Приложение «Текстовый редактор» с поддержкой отмены действий.
* Реализован интерфейс `ICommand` и конкретные команды (`Copy`, `Paste`, `Insert`, `Delete`).
* Реализован `CommandInvoker` для поддержки истории **Undo/Redo**.
* Добавлен парсер команд из текстового файла.

### 3. `Lab3_Refactoring_Football` — Рефакторинг и паттерн «Стратегия»
Консольное приложение для учета футбольных матчей.
* Проведен рефакторинг «плохого» кода с удалением громоздких `switch/if-else`.
* Внедрен паттерн **«Стратегия»** для гибкой оценки производительности команды.
* Продемонстрировано соблюдение принципов **SRP** (Single Responsibility Principle).

### 4. `StudentRegistration` — WinForms Приложение (.NET 8.0)
Заготовка системы регистрации студентов.
* Создан проект Windows Forms.
